# 🖨️ Controle de Estoque de Toners

Sistema simples e prático para gerenciar o estoque de toners de impressora, permitindo acompanhar entradas, saídas, saldo disponível e alertas de reposição.

---

## 📌 Sobre o Projeto

O **Controle de Estoque de Toners** foi criado para facilitar o dia a dia no gerenciamento de suprimentos de impressão, evitando a falta de materiais e mantendo o histórico de movimentações sempre organizado.

### Principais funcionalidades:
* Cadastro e consulta de toners.
* Registro de entradas (reposições) e saídas (retiradas).
* Histórico de movimentações.
* Alerta visual para itens com estoque baixo.
